# Guided Start–Stop Session Specification

## Session states

```text
PRECHECK
→ PREPARE
→ ACTIVE_LOW
→ ACTIVE_RISING
→ WARNING
→ PAUSED_RECOVERY
→ RESUME_READY
→ COMPLETED
→ POST_CHECK
```

Alternate terminal states:

```text
EARLY_COMPLETION
USER_CANCELLED
SAFETY_ABORT
TIME_LIMIT_REACHED
```

## Precheck

Ask:

- pain or irritation;
- anxiety 1–10;
- current arousal 1–10;
- enough private time;
- willingness to follow stop prompts.

## Prepare — 90 to 120 seconds

- breathing orb;
- relax jaw, abdomen, thighs, buttocks;
- choose sound/haptics;
- remind user not to chase duration.

## Active controls

- three large one-hand zones that preserve the internal 1–10 values:
  - **Still calm** maps to 1–4;
  - **Starting to rise** maps to 5–6;
  - **Near the limit** maps to the adaptive threshold and starts the stop transition;
- a fixed **Pause — hands off** button that never requires scrolling;
- a fixed **Almost too late** button;
- an always-available **Finish** action;
- no visible duration while the active state is running.

## Threshold behavior

### Level 1–5

Soft blue/indigo pulse. Minimal haptic.

### Level 6

Amber edge glow, single gentle haptic, copy:

> Slow down. Let your body soften.

### Level 7 or adaptive threshold

Red warning wave, stronger haptic, stop instruction:

> Stop now. Hands off. Breathe.

### “Almost too late”

Immediate emergency pause presentation. No punitive language.

## Recovery

- countdown range 30–120 seconds with the remaining wait shown explicitly;
- animated breathing orb;
- three body-state zones using the same control positions as the active state;
- a disabled resume action that explains whether time or intensity is still blocking it;
- resume only after reaching target level or choosing to end;
- private and guided sessions use the same active and recovery controls.

## Completion

The session can end after target cycles, time limit, or user choice. Erection loss is not failure and does not require compensatory stimulation.

## Maximums

- Default session cap: 20 minutes.
- Absolute guided cap: 25 minutes.
- Maximum cycles: 5.
- No automatic “try again” after early ejaculation.

## Post-check

- cycles completed;
- late-stop event;
- tension level;
- irritation/pain;
- anxiety after session;
- outcome feeling;
- optional note.
